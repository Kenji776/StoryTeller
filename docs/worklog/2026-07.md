## 2026-07-27 — Round-based turns, feasibility gate, newbie advisor

**Goal:** Make play properly round-based (initiative roll, order, 3-minute turns),
validate that a proposed action is something the character could actually attempt,
and give first-time players an assistant that suggests possible moves.

**Changed:**
- `lobbyCombat.js` — `rollInitiative` (d20 + DEX mod, shared comparator); `startGame`
  now rolls instead of using socket registration order; `nextTurn`/`turnInfo` carry a
  round number; a returning player keeps the seat they already rolled.
- `lobby/turnAttempts.js` — 3-strike tracking on the persisted lobby.

- `actionFeasibility.js` — deterministic hard checks plus a cheap-LLM judge.

  the clock, forfeit the turn on the third failure. Four modes; default `observe`.
- `newbieAdvisor.js` — ranked, plain-language suggestions, filtered through the same

- `turnTimer.js` — `resumeTurnTimer`, `skipTurn`, and `turnDeadlineAt`.
- `server.js` — gate in `action:submit`, `advisor:ask` handler, initiative announced.

**Decisions:** One capability model with two consumers, so the advisor can never
recommend what the gate would reject — enforced in code, not asked for in a prompt.

and, three times over, their turn. The gate and the judge both fail open.

## 2026-07-27 — Pluggable TTS with a local speech server

**Goal:** Let narration run through a self-hosted TTS server instead of
ElevenLabs, with the host choosing the engine and voice per lobby.

**Changed:**
- `services/tts/` — new provider layer: `registry.js` (the only list of engines
  plus selection policy), `narrate.js` (frames → Socket.IO, engine-agnostic),
  `wavTiming.js`, and adapters for the local server and ElevenLabs.
- `routes/ttsService.js` — reduced to HTTP translation; gained
  `/api/tts/providers` and a `provider` parameter on the voice routes.
- `lobby/lobbySettings.js` — `ttsProvider`, and a per-provider voice memory so
  switching engines does not lose the voice chosen for the other one.
- `server.js` — boot probe, `resolveTTS`, `ttsActiveFor`, `LOCAL_TTS_URL`.
- `client/tts.js` — buffered Blob playback beside the MediaSource path.
- `client/components/options.html` — engine dropdown; voices reload per engine.

**Decisions:** [ADR 0005](../decisions/0005-pluggable-tts-with-a-local-server.md).
The local server's URL is an env var, not a lobby setting — the server issues that
request, so a host-editable field would be an SSRF vector. Word timings are
approximated from the WAV duration rather than dropping the highlight feature.
Declined transcoding to MP3 (needs ffmpeg; project has no native deps) and Web
Audio streaming (disproportionate for an engine running 11× realtime).

**Verification:**
- `npm test` → 815 pass, 0 fail (was 609). RED observed before each unit per `TDD-2`.
- `npm run test:integration` → 7 pass against the real server on 127.0.0.1:8199;
  re-run with an unreachable URL → 7 skipped, 0 failed.
- Live boot: both engines detected; `/api/tts/providers` reports both; voices list
  from each; local preview returns 139 KB of `audio/wav`; unknown voice → 500.

**Open:**
- **The browser half is unverified.** No DOM harness exists and adding one means a
  dependency this project has avoided, so `client/tts.js` buffered playback and the
  new options dropdown are syntax-checked and reviewed only, never run in a browser.
  This is the first thing to exercise by hand.
- Player lines fall back to the DM's voice on any non-ElevenLabs engine, because a
  character sheet's `voice_id` is an ElevenLabs id. Mapping characters onto local
  voices is not done.
- Local audio is uncompressed WAV: ~48 KB per second of speech over the socket.
  Fine on loopback or LAN, not over a WAN.
- Buffered synthesis means first-audio latency scales with narration length —
  roughly 12 s of silence for a 2000-character narration.
- `keyfile.age` sits untracked **and unignored** in the repo root (`GIT-5`).
  Pre-existing, not introduced here, but one `git add -A` from being committed.

## 2026-07-27 — Admin console: first run in a real browser

**Goal:** Actually look at the rebuilt console, three phases after the last time
anything was seen rendered.

**Driven** in headless Chrome over CDP with a small scratch script — no new
dependency, `ws` is already transitive through socket.io, and the admin session is
minted inside the driver process so the password is never typed into the page or
captured in a screenshot. Twenty-eight real lobbies were already on disk.

**Three defects found that no unit test could have caught:**
- `#root` kept its `.boot` class after mounting. That class is
  `display:grid; place-items:center`, so the entire console shrink-wrapped into a
  column floating in the middle of the window instead of filling it.
- Adjust and Set rendered stacked rather than side by side — the whole point of
  the inspector. `.adjust-set` asked for `minmax(13rem, …)` inside a 22rem column,
  so only one track ever fit. The inspector is now 30rem, the tracks 11.5rem, and
  each action is one line: a number, an optional reason, a verb.
- `element.hidden = true` did nothing to the armour fields, because
  `.control-row { display: flex }` beats the `[hidden]` user-agent rule. Weapons
  showed an AC box. Fixed with an explicit `[hidden] { display: none !important }`.

**Confirmed working against real data:** Round reads 11 rather than 1 — the
`publicState` fix from phase 1, visible. Party table, HP bars, condition and
"away" chips, the enemies table the old panel never had, and the Turn section's
empty-order recovery all render correctly. No page errors in any section.

**Open:** Sections beyond the Play group are still placeholders. The compact
inspector rows are labelled by placeholder plus `aria-label` rather than a visible
caption; that is a deliberate density trade and worth a second opinion.

## 2026-07-27 — The local speech server's address becomes host-configurable

**Goal:** The engine reported "unavailable" because the speech server is not on the
default `127.0.0.1:8199`. Let the host say where it is, test it, and load its voices.

**Changed:**
- `services/tts/localConfig.js` — new. URL validation with a private-network
  requirement, plus load/save of the persisted address.
- `routes/ttsService.js` — `POST /api/tts/local/url` validates, dials, lists
  voices, persists, and marks the engine available in one round trip.
- `server.js` — the address is a live mutable holder seeded from
  `server/data/tts-config.json`, falling back to `LOCAL_TTS_URL`.
- `providers/localServer.js` — an aborted request now reports a timeout instead of
  "This operation was aborted", which is shown to the host verbatim.
- `components/options.html` — address field, Test button, live status. The local
  engine stays selectable while disconnected.
- `package.json` — `npm test` no longer recurses into `server/test-integration/`.

**Decisions:** [ADR 0006](../decisions/0006-host-configurable-local-tts-address.md),
which amends ADR 0005. The SSRF concern that made this an env var is answered by
constraint instead: the resolved address must be private, all of them, with
link-local excluded because of the cloud metadata endpoint.

**Verification:**
- `npm test` → 1207 pass, 0 fail. `npm run test:integration` → 7 pass.
  RED observed before each unit per `TDD-2`.
- Live: booted pointed at a wrong address to reproduce the report, then set the
  real one through the API — voices loaded, address persisted, and after a restart
  with the same stale `LOCAL_TTS_URL` still set, the saved address won.
- Rejections check out: a public host, an address with a path, and an unreachable
  LAN host each return a message written for a human.

**Open:**
- **Still unverified in a browser.** The address field, Test button, and the
  buffered playback path are syntax-checked and reviewed only.
- A `TDD-9` violation I introduced last session and fixed here: the integration
  test was being collected by the unit tier, because `node --test server/`
  recurses. The unit command now lists its directories.
- Any lobby host can repoint the server-wide speech address, affecting other
  lobbies. Noted in ADR 0006 as an accepted widening.
- Concurrent work by another agent landed on this branch during the session
  (admin console, incident log, repairs). All 1214 tests pass together.

## 2026-07-27 — Two defects that would have made the long run pointless

**Goal:** before spending a 120-turn game on it, make sure the events the run is
meant to exercise can actually fire.

**Changed:**
